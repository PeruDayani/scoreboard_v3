# Basketball Projects

A small collection of basketball-related apps built for fun.

- **Hidden Scoreboard** — NBA scores with spoilers kept under wraps
- **Fantasy drafts** — Making the All-Star game matter

## Setup

```bash
npm install
cp .env.sample .env.local
```

Add your `NBA_API_KEY` to `.env.local`, then:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
